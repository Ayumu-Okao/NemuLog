自動記録の設定（Android）

無料アプリ「MacroDroid」で、スマホを置いた時刻とロック解除した時刻をねむログに送ります。一度設定すれば、朝スマホを開くだけで睡眠が記録されます。

しくみ

画面オフ→時刻を覚える→ロック解除→2時間以上たっていたら→ねむログを開いて記録

夜中に少しスマホを見ても、ねむログ側で1回の睡眠にまとめ「夜中に起きた回数」として数えます。日中にスマホを放置した時間は、設定の「夜の開始〜終了」の外なので睡眠として扱いません。

0. 準備

  1. Chromeでねむログを開き、メニューの「ホーム画面に追加」（または「アプリをインストール」）でインストールします。
  2. Playストアから MacroDroid をインストールします。
  3. Androidの設定で MacroDroid の「バッテリーの最適化」をオフにします（夜間に止められないようにするため）。

1. 変数を作る

  1. MacroDroid の「変数」画面で グローバル変数 を2つ作ります。
  2. sleep_off（整数）
  3. gap（整数）

2. マクロ①「スマホを置いた」

  1. トリガー：画面オン/オフ →「画面オフ」
  2. アクション：変数を設定 → sleep_off に値 [system_time] を設定

[system_time] は「マジックテキスト」ボタンから「システム時刻（秒）」を選ぶと入ります。

3. マクロ②「起きた」

  1. トリガー：デバイスのロック解除
  2. アクション：変数を設定 → gap に式 [system_time]-[v=sleep_off] を設定（「式」や「計算」の入力モードを選びます）
  3. アクション：If 句 → 条件「変数 gap が 7200 以上」（7200秒＝2時間）
  4. If の中にアクション：ウェブサイトを開く → URLにねむログの設定画面でコピーしたURLを貼り、{OFF} を [v=sleep_off]、{ON} を [system_time] に置き換えます
  5. End If

「ロック解除」トリガーを使うのは、通知で画面が点いただけのときに反応しないようにするためです。

4. 動作確認

  1. MacroDroid のマクロ②を開き、条件を一時的に 60（1分）にします。
  2. 画面を消して1分以上待ち、ロック解除します。
  3. ねむログが開き、トーストが出れば成功です（日中は「日中のため記録していません」と出ます。これも正常です）。
  4. 確認できたら条件を 7200 に戻します。

うまく動かないとき

  • ブラウザで開いてしまう：ねむログをChromeから「インストール」し直すと、アプリ側で開くようになります。
  • 記録の時刻がずれる：[system_time] がミリ秒でも秒でも自動で判別します。それ以外の形式になっていないか確認してください。
  • 寝る前に動画を見ながら寝落ち：画面が消えた時刻から記録されます。気になる場合は履歴をタップして手で直せます。
